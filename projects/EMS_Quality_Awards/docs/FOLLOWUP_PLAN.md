## แผนปฏิบัติการ (3 ระยะ)

### ระยะ A — 48 ชม. แรก (ด่วนที่สุด)

1. **โทรติดตาม** อปท. ที่มีเบอร์มือถือผู้ประสานงาน (รหัส 002–061 ในชีต)
2. **ส่งอีเมล** ไปยัง saraban / อีเมลหน่วยงาน (12 แห่งที่มีอีเมล)
3. **เร่งกรณีพิเศษ:** อบจ.สงขลา (#003) — ยืนยันคำขอ 2 บูธ แยกจากเส้นทางผู้ชนะ
4. **บันทึกผล** ทุกครั้งใน Spreadsheet → รัน `make sync`

### ระยะ B — สัปดาห์นี้

1. ประสาน **สสจ.** ทุกจังหวัดผ่านหนังสือเชิญ (01 ใน Drive)
2. ประสาน **ท้องถิ่นจังหวัด** (หนังสือ 02)
3. ติดตาม **35 แห่งที่ไม่มีอีเมล** — ขอช่องทาง Line/โทรสำรอง
4. แก้เบอร์โทรที่เป็นเลขสำนักงาน (ขึ้นต้น 0x) ให้ได้เบอร์มือถือผู้ประสานงาน

### ระยะ C — ก่อนวันประชุม

1. ยืนยันผู้รับโล่ + รูปแบบเข้าร่วมทุกหน่วย
2. สรุปที่พัก/เดินทางส่ง อบจ.กระบี่
3. เป้าหมายอัตราตอบรับ **100%** หรือบันทึกเหตุผลไม่เข้าร่วมครบ
